get started

From zero to your own dialect

  1. 01

    Download the zip

    Grab pengu-starter.zip — interpreter, examples, and config in one tiny package.

    download .zip
  2. 02

    Run your first program

    python pengu.py examples/hello.pengu — no installs, no config, no ceremony.

    $ python pengu.py examples/hello.pengu
Hello from Pengu!
Welcome, builder
  3. 03

    Open the hood

    pengu.py is under 300 lines of plain Python. Change say to print, invent keywords, add features.

    # pengu.config.json
{ "print": "say", "function": "flock",
  "condition": "slide", "loop": "for" }
  4. 04

    Ship your dialect

    Name it, publish it, tell the world. Pengu is the starter — you are the language designer now.
